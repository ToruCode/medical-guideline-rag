# Retrieval baseline results

Aggregate Recall@k/MRR measurements from
`scripts/evaluate_retrieval_baseline.py`, run manually against real
guideline documents kept entirely locally. See
`docs/evaluation-dataset-format.md` for the dataset format and
`docs/adr/0014-real-data-retrieval-baseline.md` for the full design
reasoning.

Only aggregate numbers and measurement configuration are recorded
here. Document titles/publishers are anonymized (e.g. `"Guideline
A"`); the underlying PDF, dataset, questions, and expected
pages/chunks are never committed - see `CLAUDE.md`'s data/copyright
rules.

To add an entry: run `scripts/evaluate_retrieval_baseline.py`, review
the Markdown snippet it prints for anything identifying, then paste it
below (most recent first).
